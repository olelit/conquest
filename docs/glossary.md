# Глоссарий Conquest — сущности игры

Общий словарь для общения: используй эти термины, они однозначно соответствуют коду.

## Карта и клетки

- **Гекс** — клетка карты. Поля: `q`, `r` (аксиальные координаты), `terrain`, `ownerId` (владелец), `attackerId`/`defenderId` (участники битвы), `attackInvestment`/`defenseInvestment` (вложенные очки), `battleProgress` (прогресс захвата).
- **Террейн** — тип местности: `grass` (равнина), `forest` (лес), `mountain` (гора), `water` (вода), `desert` (пустыня), `mine` (шахта). У каждого своя стоимость захвата (150/250/450/350/200/450).
- **Карта** — набор гексов. Типы: `normal` (16×12), `long` (24×9), `island` (15×13), `round` (19×19). `qOffset` — сдвиг колонок (для карт с отрицательными q).

## Игроки и состояния

- **Игрок** — участник партии: `id`, `name`, `points` (очки), `isAi`, `capital` (столица `{q,r}`), `eliminated` (выбыл), `incomeMultiplier` (множитель дохода).
- **Столица** — первый захваченный гекс игрока. Потеря столицы = **выбытие**.
- **Выбытие** — игрок проиграл: его территория нейтрализуется (90%) или делится на новых ИИ (10%).
- **Очки** — ресурс для действий. Старт: 1000. **Лимит очков** = 1000 + (число гексов × 50). Доход: 2 очка/гекс/сек (+3 за шахту).
- **Армия** — процент текущих очков, отправляемый в действие (0–100%, поле «Армия»).
- **Резерв армии** — очки, занятые армией: `floor(points × армия% / 100)`; учитывается при проверке бюджета.
- **Сложность** — `easy`/`medium`/`hard`; множитель дохода ИИ 0.5/0.75/1.
- **Комната** — игровая сессия. `aiMode` = соло (игра с компьютером), мультиплеер — комната с людьми + добивающие ИИ.

## Действия и бои

- **Действие** — `capture` (захват нейтрального гекса), `attack` (атака чужого), `defend` (защита).
- **Битва** — идёт за гекс, пока `attackerId` не null. Каждый тик вложения тратят по 10, прогресс растёт у того, чьё вложение больше (+1/тик), при ±5 битва завершается победой.
- **Захват** — первый гекс бесплатный; захват у границы врага начинает битву (пул = стоимость гекса).
- **Отрезание** — захват «шейки»: часть территории без столицы становится нейтральной.
- **Окружение** — полностью окружённая врагом территория переходит к окружившему.
- **Тик** — игровой такт 500 мс: доход, битвы, окружение, действия ИИ.

## UI-элементы (термины)

- **HUD** — таблица игроков слева сверху: имя, клетки, очки/лимит, доход, метка «выбыл».
- **Игровой лог** — панель справа снизу со списком событий («X захватил...», «Битва окончена...»).
- **Панель армии** — панель снизу по центру с полем армии (проценты).
- **Баннер** — большая надпись по центру («Победа», «Поражение»).
- **Тултип гекса** — информационная карточка под гексом при наведении.
- **Шапка** — верхний правый угол: название комнаты, пауза, бургер-меню.
- **Камера** — панорамирование WASD/стрелками, зум колесом; сдвиг привязан к целым пикселям.

## Серверное

- **Тик-цикл** — `Room.tick()`: доход → битвы → выбытие/отрезание → окружение → действия ИИ → победитель.
- **ИИ-действие** — одно действие в секунду на каждого ИИ.
- **Статистика** — JSON-файлы `server/stats/*.json` (события партии: действия, реакции, снапшоты).
- **WS-сообщения** — `capture/attack/defend/pause/restart/start-solo/create-room/join-room/...`.
- **Маркер столицы** — звезда ★ на гексе столицы и в тултипе.
