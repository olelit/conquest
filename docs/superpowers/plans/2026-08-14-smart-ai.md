# Умный ИИ — атака слабейшего: план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** ИИ выбирает целью атаки самого слабого соседнего врага (минимум клеток, при равенстве — минимум очков), внутри него — самый дешёвый по террейну гекс.

**Architecture:** Одна правка блока выбора вражеской цели в `chooseAiAction` (server/src/ai.ts): группировка смежных вражеских гексов по владельцу → слабейший владелец → дешёвый гекс.

**Tech Stack:** Node.js + TypeScript + vitest.

## Global Constraints

- Тесты сервера: `npx vitest run` из `server/` (197 существующих тестов зелёные).
- Навык работает на всех уровнях сложности (разница уровней — только множитель дохода).
- Существующие приоритеты ИИ не меняются.

на:

```ts
  const enemyHexes = state.hexes.filter(
    (hex) =>
      hex.ownerId !== null &&
      hex.ownerId !== aiId &&
      relation(state, aiId, hex.ownerId) === 'war' &&
      hasAdjacentOwner(state, hex.q, hex.r, aiId),
  );
  if (enemyHexes.length > 0) {
    // атака слабейшего соседнего врага: минимум клеток, при равенстве — минимум очков
    const weakness = (ownerId: number) => {
      const owner = state.players.find((p) => p.id === ownerId);
      return { hexes: hexCount(state, ownerId), points: owner?.points ?? 0 };
    };
    const owners = [...new Set(enemyHexes.map((h) => h.ownerId as number))];
    owners.sort((a, b) => {
      const wa = weakness(a);
      const wb = weakness(b);
      return wa.hexes - wb.hexes || wa.points - wb.points;
    });
    const target = owners[0];
    const hex = enemyHexes
      .filter((h) => h.ownerId === target)
      .sort((a, b) => terrainCost(a.terrain) - terrainCost(b.terrain))[0];
    const cost = terrainCost(hex.terrain);
    if (ai.points >= cost) return { type: 'attack', q: hex.q, r: hex.r, points: cost };
  }
```
