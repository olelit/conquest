# Дизайн: Битвы v3 и UI-правки

Дата: 2026-08-12
Статус: утверждён пользователем

## Контекст

Пользователь недоволен текущей механикой битв и UI. Требования:

1. Битва: захват по перевесу пула (не по обнулению).
2. Меньше гор на всех картах.
3. Первый город (гекс) не создавать на воде.
4. Информация о гексе — при наведении, а не при клике.
5. Одинарный клик = захват (действие), без шага «выбрать и посмотреть».
6. Игровое поле занимает весь экран; интерфейс накладывается поверх.
7. WASD двигает камеру, если карта не влезает в экран (при зуме).
8. Короткая анимация захвата (перекраска) + уменьшение тика до 500 мс.

## Механика битвы v3

### Правила

- Каждый тик оба пула (`attackInvestment`, `defenseInvestment`) тратятся по
  `DRAIN_PER_TICK` (10), не ниже 0, пока битва активна.
- `battleProgress` — знаковое число:
  - пул атакующего > пула защитника → `battleProgress += 1`;
  - пул защитника > пула атакующего → `battleProgress -= 1`;
  - равенство → прогресс не движется.
- Завершение:
  - `battleProgress >= CAPTURE_TICKS` (5) → атакующий захватывает: гекс → атакующему
    (у нейтрального забирает, у вражеского отбирает); остаток пула атакующего
    возвращается в его очки; пул защитника сгорает.
  - `battleProgress <= -CAPTURE_TICKS` → защитник отбивает: свой гекс остаётся у
    владельца, нейтральный спорный гекс достаётся защитнику; остаток пула защитника
    возвращается; пул атакующего сгорает.
- Ничья: оба пула дошли до 0 в один тик → битва заканчивается без победителя,
  гекс остаётся у текущего владельца, возвращать нечего.
- Вложения больше не сбрасывают прогресс и не «замораживают» пулы — они лишь
  меняют лидера. Смена лидера меняет направление прогресса (знаковый).
- Первая атака — минимум `terrainCost`; доливки ≥ 1 (как в Этапе 1).
- Нейтральный гекс у врага: вложение стоимости открывает битву (пул = стоимость,
  защитник может вложиться — перевес решает).

### ИИ

- Защита своего/оспаривание нейтрального: если пул врага ≥ своего → вложить
  `разница + 1` (выйти вперёд). Частный случай «враг захватывает при своём пуле 0»
  покрывается этим же правилом.
- Долив своей атаки: если пул обороны ≥ своего → вложить `разница + 1`.
- Захват нейтралов и атака границы — как в Этапе 2.

## Террейн

- Суша генерируется с весами: равнина 45%, лес 25%, пустыня 20%, горы 10%
  (было равномерно по 20% гор); шахты — из гор с шансом `mineChance` (0.1).
- Тест распределения на большой выборке с широкими границами (горы 5–15%).

## Первый гекс не на воде

- `validateCapture`: если `hexCount(playerId) === 0` и `hex.terrain === 'water'` →
  ошибка «Первый гекс не может быть на воде».
- ИИ `chooseFirstCapture` исключает воду из кандидатов.

## Web UI

### Наведение вместо клика

- Hover на любом гексе → тултип: местность, стоимость захвата, владелец
  (имя игрока), при битве — пулы обеих сторон и знаковый прогресс захвата
  (кто лидирует, полоса прогресса).
- Клик — только действие:
  - нейтральный захватываемый → захват (армия из ползунка);
  - вражеский соседний → атака на `army`;
  - гекс в битве (мой атакующий) → долив;
  - гекс в битве (я защищаюсь/соседний для нейтрального) → защита;
  - иначе — ничего (информация и так на наведении).
- Убирается выбор гекса (`selected`), панель ArmyBar — только ползунок армии.

### Полноэкранное поле

- Карта: `position: fixed; inset: 0`, SVG заполняет экран.
- HUD (список игроков), ползунок армии, лог, кнопки — поверх карты
  (фиксированные позиции, как сейчас, но на фоне карты).

### WASD — камера

- Клавиши WASD/стрелки двигают камеру (сдвиг viewBox на ~10% ширины вида за
  событие, при зажатой клавише — непрерывно через rAF), с клампом в границах
  базового вида карты.

### Анимация захвата

- Смена `ownerId` гекса (битва/окружение) → CSS-перекраска ~0.6 с
  (короткий flash), детект по разнице ownerId между тиками.

## Тик

- `CONQUEST_TICK_INTERVAL_MS` по умолчанию 500 (было 1000).

## Файлы

Сервер:
- `server/src/rules.ts` — знаковый `battleProgress`, новая механика тика;
- `server/src/ai.ts` — правило перевеса, вода в первом захвате;
- `server/src/map.ts` — веса террейнов;
- `server/src/config.ts` — тик 500.

Web:
- `web/src/components/HexMap.vue` — тултип для любого гекса, WASD-камера,
  анимация захвата, полноэкранная карта;
- `web/src/App.vue` — клик-действие, без выбора, полноэкранный layout;
- `web/src/components/ArmyBar.vue` — только ползунок;
- `web/src/types.ts` — без изменений (battleProgress уже число).
