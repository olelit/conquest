# Дизайн: контекстное меню правой кнопки + чистка игрового лога

Дата: 2026-08-13

## Обзор

Основа для будущих фич (дипломатия, крепость): вертикальное контекстное меню по правой кнопке мыши. Пункты-заглушки. Плюс удаление сообщений о захватах из игрового лога.

## 1. Контекстное меню

- Новый компонент `web/src/components/ContextMenu.vue`:
  - вертикальный список тёмных пунктов у позиции курсора (как ПКМ в ОС);
  - `position: fixed`, координаты от события `contextmenu`;
  - закрытие: клик в другом месте, ESC, повторная ПКМ, потеря фокуса окна, смена гекса наведения;
  - содержимое определяется владельцем гекса:
    - свой гекс (`ownerId === myPlayerId`): пункт «Построить крепость» (disabled, подпись «будет доступно позже»);
    - чужой гекс (владелец есть и не мой): пункты «Война», «Мир», «Союз» (disabled, «будет доступно позже»);
    - нейтральный гекс или вода: меню не открывается.
- `HexMap.vue`: слушает `contextmenu` на hex-group (сейчас `@contextmenu.prevent` стоит на контейнере), эмитит `contextmenu` с `{ hex, x, y }`; при показе меню ховер-тултип скрывается.
- `App.vue`: держит состояние меню (`contextMenu = ref<{ hex: Hex; x: number; y: number } | null>`), рендерит `ContextMenu`, обрабатывает закрытие.
- Иконки пунктов не требуются (текстовые пункты).
