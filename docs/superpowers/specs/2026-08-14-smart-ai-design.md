# Дизайн: умный ИИ — атака слабейшего

Дата: 2026-08-14

## Обзор

ИИ при выборе цели атаки предпочитает самого слабого соседнего врага (минимум клеток, при равенстве — минимум очков), внутри него — самый дешёвый по террейну гекс. Навык работает на всех уровнях сложности (разница уровней — только множитель дохода).

## 1. Правило (server/src/ai.ts)

В `chooseAiAction` блок выбора вражеской цели (`enemyHexes`) заменяется:

1. Среди вражеских владельцев смежных гексов выбрать слабейшего:
   - `hexCount(owner)` минимальный;
   - при равенстве — минимальный `points`.
2. Из гексов этого владельца, смежных с ИИ, выбрать самый дешёвый по `terrainCost`.
3. Атаковать его (вложение = стоимость террейна, как сейчас).

- Импорты: `hexCount` уже есть; добавить `terrainCost` (уже есть), при необходимости `findHex`/`isAdjacent` (проверить текущие импорты).
- Существующие приоритеты (защита своих гексов, продолжение своих атак, захват нейтральных, постройка крепостей) не меняются.
- Поведение против ИИ и против человека одинаковое.

## 2. Тесты (server/test/ai.test.ts)

- ИИ атакует гекс слабейшего из двух соседних врагов (1 клетка vs 10 клеток).
- При равенстве клеток — враг с меньшими очками.
- Внутри выбранного врага — самый дешёвый террейн.
