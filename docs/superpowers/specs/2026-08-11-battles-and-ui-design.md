# Дизайн: новая механика сражений и UI-правки (Этап 1)

Дата: 2026-08-11
Статус: утверждён пользователем

## Контекст

Сейчас битва устроена так: атака/защита копят инвестиции, битва длится фиксированные
`BATTLE_TICKS` (5) тиков, победитель — сторона с большей инвестицией, ей возвращается
`max(attack, defense)`. Любое вложение сбрасывает прогресс битвы.

Новая механика: вложенные в битву очки тратятся по 10 за тик у обеих сторон; когда пул
одной стороны дошёл до 0, вторая начинает захватывать гекс; проигравшая сторона может
продолжать вкладываться, пока захват не завершён.

Этот этап также включает UI-правки: цифры битвы переносятся из гекса в модалку при
наведении, бургер и пауза переезжают вправо, добавляется зум карты колесом мыши.

Этап 2 (настройка игры, комнаты, N игроков) — вне рамок этой спеки.

## Механика сражений

### Состояние гекса в битве

Поля `HexState` остаются прежними, меняется семантика:

- `attackInvestment` — текущий пул атакующего;
- `defenseInvestment` — текущий пул защитника;
- `battleProgress` — прогресс захвата (0..`CAPTURE_TICKS`), больше не «тики битвы»;
- `attackerId`, `defenderId`, `ownerId` — без изменений.

Фаза битвы (трата или захват) выводится из пулов и не хранится отдельно:
- оба пула > 0 → фаза траты;
- ровно один пул = 0 и второй > 0 → фаза захвата (победитель — сторона с пулом > 0);
- оба пула = 0 → битва завершается в этот же тик (ничья).

### Тик битвы (`tickBattles`)

Для каждого гекса с `attackerId !== null`:

1. **Фаза траты** (оба пула > 0): оба пула уменьшаются на `DRAIN_PER_TICK` (10),
   но не ниже 0.
2. **Переход в захват:** если после вычета ровно один пул = 0, а второй > 0 —
   `battleProgress` увеличивается на 1 за тик; **оба пула в фазе захвата заморожены**
   (не тратятся).
3. **Завершение захвата:** `battleProgress >= CAPTURE_TICKS` (5) →
   - `hex.ownerId` = сторона с пулом > 0;
   - при защите нейтрального гекса (`ownerId === null` до битвы) защитник, чей пул
     выстоял, получает гекс себе;
   - остаток пула победителя возвращается в его очки;
   - битва сбрасывается (`attackerId`, `defenderId`, пулы, `battleProgress` = 0).
4. **Ничья:** оба пула = 0 после вычета → битва заканчивается без победителя,
   `ownerId` не меняется, возвращать нечего, битва сбрасывается.

Пул не уходит в минус: `pool = max(0, pool - DRAIN_PER_TICK)`.

### Вложения

**Атака** (`validateAttack` / `applyAttack`):
- минимум для начала атаки = `terrainCost(hex.terrain)` (стоимость местности);
- доливки ≥ 1 очка в любой момент, пока битва не завершена;
- прочее как сейчас (гекс не свой, не нейтральный, соседний, хватает очков,
  не более одного атакующего на гекс).

**Защита** (`validateDefend` / `applyDefend`):
- вложение ≥ 1, пока битва не завершена, даже если собственный пул = 0
  (вложение отменяет захват);
- владелец защищает свой гекс всегда; нейтральный гекс под атакой — если соседний;
- чужой гекс защищать нельзя.

**Отмена захвата:** любое вложение в сторону с пулом = 0 делает пул > 0,
`battleProgress` сбрасывается в 0, битва возвращается в фазу траты.

### Нейтральные гексы

- **Без врага рядом:** захват мгновенный за `terrainCost` (как сейчас).
- **Рядом с врагом** (`hasAdjacentOwner` у соперника): вложение `terrainCost`
  открывает битву — пул атакующего = стоимость, пул защитника = 0, атакующий сразу
  начинает захват (5 тиков); враг может вложиться в защиту (если соседний) →
  захват отменяется, начинается настоящая битва с тратой; враг не вмешался →
  через 5 тиков гекс твой, вложенная стоимость возвращается.

### Экономика

- Очки пулов сгорают по 10 за тик — цена войны.
- Пул замирает в фазе захвата.
- Остаток пула победителя возвращается после завершения захвата.
- Владелец продолжает получать доход, пока гекс числится за ним
  (`ownerId` не меняется до конца захвата).

### Конфиг

- Новый: `CONQUEST_DRAIN_PER_TICK = 10`.
- `CONQUEST_BATTLE_TICKS` заменяется на `CONQUEST_CAPTURE_TICKS = 5`.

## AI

`chooseAiAction` переписывается под новую механику:

- **Защита:** на своём гексе с активной битвой или захватом врага — долить,
  если пул врага ≥ своего (минимум до перевеса); приоритет — гексы, где идёт захват.
- **Атака:** на границе, вложение ≥ `terrainCost`; доливка своей атаки, если враг
  контрит.
- **Захват нейтралов** — как сейчас (самый дешёвый свободный соседний).

## Web UI

- **Модалка битвы:** при наведении на гекс с битвой (`attackerId !== null`) над гексом
  появляется небольшое окно: пулы обеих сторон, полоса прогресса захвата,
  кто кого захватывает. Текст цифр из гекса убирается.
- **Индикация на гексе:** тонкая рамка/обводка цвета захватывающей стороны.
- **Заголовок:** бургер и кнопка паузы — в правой части экрана.
- **Зум:** только колесо мыши, центрирование на курсоре, диапазон ~0.5–3×.
